# Documentation

ドキュメントを、ポートフォリオとして公開する成果物と個人学習用の内部メモに分けて管理します。

```text
docs/
├── public/       # GitHubで公開する成果物
└── learning/     # 個人学習用。ディレクトリ全体をGit管理対象外とする
```

## Public documents

- [公開ドキュメント一覧](public/README.md)
- [Architecture](public/architecture/README.md)

公開側には、採用した設計方針、API仕様、技術選定、デプロイ・運用方法、デモシナリオを配置します。

`learning/` は初歩的な学習ノート、ローカル環境固有の手順、検討途中のメモに使用します。学習内容を正式に採用した場合は、結論と根拠を公開側へ整理して反映します。

# OWASP ASVS data

This directory contains OWASP Application Security Verification Standard 5.0.0
data used by the local search demo.

- `asvs-5.0.0-en.csv`: official English v5.0.0 release
- `asvs-5.0.0-ja.csv`: community Japanese draft from `owasp-ja/asvs-ja`

The English text is the authoritative source. The Japanese text is displayed as
a convenience and must be treated as a community draft.

Sources:

- https://github.com/OWASP/ASVS/tree/v5.0.0
- https://github.com/owasp-ja/asvs-ja/tree/master/5.0
